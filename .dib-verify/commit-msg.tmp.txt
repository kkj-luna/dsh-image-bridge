A19：四处保存统一写完整快照，不再只写一半

设置页有四处保存（删除提供商 / 保存提供商 / 保存模型设置 / 保存尺寸）写的是同一行配置。此前每条路径各写自己那部分——「保存尺寸」只写 { size }——于是存在「甲写一半、乙写另一半」的窗口：任何一次保存都可能把别的字段留在旧值上，用户在 A 处的改动可能被 B 处的保存抹掉。

现在四处统一走同一个 snapshotPatch，一次写全本页拥有的五个字段（providers / activeProviderId / modelRoutes / connectTimeoutSeconds / size），不存在只写一半的路径。

原有一条把它当成正确行为的断言（「且这一次只写 size」）已改为钉住完整快照；另加一条字段全集一致的结构性防线：四条路径写入的键名集合必须完全相同且覆盖全部字段。红-绿验证过：把 size 从快照里拿掉后，防线直接指出 missing: ["size"]，同时另有两条断言变红。

顺带修复 CHANGELOG 的一处结构缺陷：上一轮编辑误删了「依赖缺失时不再静默降级」小节标题，导致那一段正文失去归属，现已补回。
